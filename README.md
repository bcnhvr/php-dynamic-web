# 🐘 PHP Dynamic Web App

[![PHP Version](https://img.shields.io/badge/PHP-8.2%2B-777BB4?style=flat&logo=php)](https://www.php.net/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

A lightweight, clean PHP boilerplate designed for building fast, dynamic web applications.

---

## 🛠️ Features

- **Server-Side Rendering:** Clean PHP separation for views and logic.
- **Modern Styling:** Integrated dark mode CSS layout.
- **XSS Protection:** Escaped dynamic variables using `htmlspecialchars()`.
